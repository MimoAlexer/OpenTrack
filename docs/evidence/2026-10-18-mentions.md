# Mentions and personal issue subscriptions

Date: 18 October 2026. Status: shared client and server qualified and deployed; final Linux desktop package verified and installed. This M04 increment preserves the full product goal; it does not establish M07 notification or inbox delivery.

## Implemented contract

User mentions are inline, ID-only document nodes. Current authorized projections supply display names; stored plain text uses a generic marker. Existing unavailable references may remain in an edited document, while newly added references must identify enabled current readers. The eligible reader picker includes viewers. Comment origin-team restrictions also apply to their mention candidates and historical display. Reusable issue templates reject mention nodes.

Newly added unique nonself recipients produce private reference-only source intents in the same transaction as the document/comment mutation. Retained references, duplicate occurrences and committed request replay do not create duplicate intents. Removed references that are later added again are new source revisions. Intent lifetime is independent of expiring replay events and rich document revisions. Later delivery must recheck source access, preferences and source lifecycle; no alert has been delivered merely because an intent exists.

Issue subscriptions belong to the current user. Automatic sources include creator, assignment and mention; explicit subscribed/unsubscribed preferences override those sources and survive repeated automatic additions. Eligible existing issue creators/assignees are backfilled without retroactive notification intents. Subscription changes produce private durable events and restricted audit, without exposing personal preferences through general issue activity. Read-only users may manage their own preference.
