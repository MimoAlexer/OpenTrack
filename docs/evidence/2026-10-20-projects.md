# Projects qualification — 20 October 2026

This increment adds team-owned projects to the shared browser and desktop application. It follows the collaboration increment in [PR #121](https://github.com/MimoAlexer/OpenTrack/pull/121), whose required checks passed before merge. It does not complete M05 or the wider product.

![Saved project with a formatted brief, lead, dates and independent issue progress](2026-10-20-projects.png)

## Implemented behavior

- Create, find, edit, archive and restore projects within the current team's authorization boundary.
- Save a formatted brief, optional eligible lead, dates, lifecycle state and separately assessed health.
- Add or remove existing same-team issues. Composite foreign keys enforce team equality and single-project membership. Moving a linked issue requires detaching it first.
- Calculate progress from current visible scope, excluding archived/deleted issues and canceled issues from the denominator. Empty eligible scope has no percentage.
- Publish immutable authored updates with captured state, health and progress.
- Require explicit review of conflicting edits and preserve drafts. Completing or archiving a project does not complete its issues.
- Permit only the corresponding bounded API routes in the native broker.

Project briefs currently use the restricted template editor subset and share the metadata version. Independent brief history, bound attachments, mentions and issue references remain unfinished.
