## Candidate minimum wire contracts

These are proposed bounded text contracts for later M11-T03 implementation, not executed requests or a complete implementation of every provider feature. Model placeholders must come from the selected connection. Send `Content-Type: application/json`; attach credentials only in the server transport.

Anthropic requests, including model discovery, additionally send `anthropic-workspace-id: <selected-provider-workspace>` when the key is not scoped to one workspace. Provider workspace selection is separate from OpenTrack workspace authorization. A workspace-scoped key can omit this header. [Workspace selection](https://platform.claude.com/docs/en/manage-claude/authentication#select-a-workspace).

| Adapter | Exact initial request subset | Response handling |
| --- | --- | --- |
| OpenAI API | `POST https://api.openai.com/v1/responses`; body `{"model":"<selected-id>","input":[{"role":"user","content":"<text>"}],"store":false,"stream":true}`. [Create response](https://developers.openai.com/api/reference/resources/responses/methods/create). | SSE: consume `response.output_text.delta`; distinguish `response.completed`, `response.failed`, `response.incomplete` and `error`. Read terminal response usage when provided. EOF without a terminal event is interrupted. [Streaming events](https://developers.openai.com/api/reference/resources/responses/streaming-events). |
| Anthropic API | `POST https://api.anthropic.com/v1/messages`; proposed explicit header `anthropic-version: 2026-10-21`; body `{"model":"<selected-id>","max_tokens":1024,"messages":[{"role":"user","content":"<text>"}],"stream":true}`. This initial subset sends system instructions through top-level `system`; model-specific mid-conversation system messages are outside it. [Messages](https://platform.claude.com/docs/en/api/messages/create), [version policy](https://platform.claude.com/docs/en/api/versioning), [mid-conversation system messages](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages). | SSE: `message_start`, indexed content-block start/delta/stop, `message_delta`, `message_stop`; tolerate pings and unknown additive events. Usage updates in `message_delta` are cumulative, not increments to sum. An error may arrive after HTTP success. [Streaming](https://platform.claude.com/docs/en/build-with-claude/streaming). |
| Ollama native | `POST <allowlisted-base>/api/chat`; body `{"model":"<selected-name>","messages":[{"role":"user","content":"<text>"}],"stream":true}`. Read `message.content`, final `done`, `done_reason`, and reported `prompt_eval_count`/`eval_count`; durations are nanoseconds. [Chat](https://docs.ollama.com/api/chat). | Parse bounded newline-delimited JSON, not SSE. Require `done: true`, inspect the finish reason, and preserve partial text on interruption. [Streaming](https://docs.ollama.com/api/streaming). A mid-stream `{"error":"..."}` retains the original HTTP status and is failure. [Errors](https://docs.ollama.com/api/errors). |

Anthropic `message_stop` ends the provider message, not necessarily the requested user task. Interpret `stop_reason`: `tool_use` needs a separately authorized continuation; `max_tokens` and `model_context_window_exceeded` indicate truncation; refusal and pause have distinct outcomes. Never execute truncated tool input. [Stop reasons](https://platform.claude.com/docs/en/build-with-claude/handling-stop-reasons).

## SIWC remains a separate disabled contract

The following verified details prepare the optional spike without resolving Q01:

- First registration uses `dynamic_agent_client`, then persists the issued `client_id`. Generate stable opaque per-host `ext_agent_host_id`, fresh state/nonce and PKCE S256. Use the documented `127.0.0.1` loopback callback, validate ID-token signature/issuer/audience/expiry/nonce, and require granted `chatgpt.tokens.use.direct` before inference. Email alone is not registration identity. [Registration](https://developers.openai.com/siwc/token-sharing-open-source/sign-in).
- SIWC `GET /v1/models` returns **`models[]`**, with `slug`, `display_name`, `visibility`; show entries with `visibility: "list"` in server order and send the selected `slug`. This differs from API-key **`data[].id`** at the same URL. Refresh on account switch. Require `response.completed`; plan-limit failures can arrive after text. [Models and inference](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference).
- The HTTP preview requires `store: false`, `stream: true` and history in array `input`; it rejects explicit system message items. Omit unsupported fields including `background`, `conversation`, `previous_response_id`, `max_output_tokens`, `max_tool_calls`, `temperature`, `top_p`, `metadata`, `truncation`, and `user`. Functions/custom tools need the documented namespace or `additional_tools` shape. Image generation, file search, Code Interpreter, native computer use, hosted MCP/connectors and `tool_search` are unavailable; web search is account/model dependent. [Preview restrictions](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).
- Refresh with the issued client ID and current rotating token; serialize refresh ownership. Stop requests at sign-out, attempt discovered refresh-token revocation, clear local tokens and report unconfirmed remote revocation accurately. [Sessions](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions).
- The VM guide completes OAuth locally, securely transfers the selected session, retains the VM's own host ID and makes the VM the refresh owner. Host-specific attribution/revocation for transferred sessions is unavailable. This does not settle OpenTrack's multi-user custody question. [VM guidance](https://developers.openai.com/siwc/token-sharing-open-source/self-hosted-vms).

## Drift and minimum implementation decisions

1. **Anthropic version changed after the existing 17 October research.** `2026-10-21` removes `temperature`, `top_p`, `top_k`, rejects documents directly in assistant messages, and rejects non-empty user-text citations. Some reference examples still display `2023-06-01`; do not silently mix their assumptions. Proposed new adapter pin: `2026-10-21`, omitting sampling fields. Older-version compatibility, if chosen, needs its own explicit fixture record. [Migration guide](https://platform.claude.com/docs/en/api/migration-2026-10-21).
2. **Local URL does not prove local inference.** For a local-only support claim, configure Ollama cloud features off (`OLLAMA_NO_CLOUD=1` or `disable_ollama_cloud: true`), restart, verify the setting and a local model, and test with external inference unavailable. An operator declaration alone is not measured network isolation. [Ollama FAQ](https://docs.ollama.com/faq#how-do-i-disable-ollamas-cloud-features).
3. **Stop is not confirmed remote cancellation.** OpenAI's cancel endpoint supports background responses only; SIWC forbids `background`. A foreground transport abort cannot be presented as proof of provider-side cancellation or zero additional cost. [Cancellation](https://developers.openai.com/api/reference/resources/responses/methods/cancel). Anthropic/Ollama cancellation and post-abort accounting still need actual-runtime evidence.
4. **Coding-runtime evidence is separate.** `codex exec --json` exposes JSONL lifecycle events; SDK automation and app-server clients serve different purposes. Existing native auth files are not an OpenTrack credential exchange. [Noninteractive contract](https://learn.chatgpt.com/docs/non-interactive-mode), [SDK](https://learn.chatgpt.com/docs/codex-sdk). App-server authentication is not permitted for commercial/hosted services; use the eligible SIWC path rather than bypass Q01 through runtime auth. [App-server authentication](https://learn.chatgpt.com/docs/app-server#authentication). Claude Agent SDK runs a coding runtime, not merely Messages inference. [Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview). No runtime/version/isolation or Q02 distribution acceptance was executed here.

Later implementation must preserve [F33](../features/F33_PROVIDER_CONNECTIONS.md) and [the AI architecture](../ai/AI_ARCHITECTURE.md): separate provider/auth-mode parsers; explicit connection/model and data destination; private encrypted credentials; local revocation fencing; advertised versus probed capabilities; five-minute account-scoped metadata cache; null unknown usage/cost; bounded streams/tool JSON; local durable history; reviewed, deduplicated tool writes. Never silently switch provider, account, model, paid route or cloud destination.
