# Native contract CI qualification

Issue: [#120](https://github.com/MimoAlexer/OpenTrack/issues/120). Date: 20 October 2026.

## Scope and design

The root Rust workspace excludes the native desktop workspace. A missing native issue-reference route was caught by the desktop OpenAPI parity test and fixed separately in [#119](https://github.com/MimoAlexer/OpenTrack/issues/119). The implementation workflow now includes an independent, consistently named `native-contracts` job using `desktop/scripts/check.sh --core` against the production desktop crate.

The job consumes the existing conservative `verify` decision. Desktop, API-contract, toolchain, workflow and verification-script changes run native checks. Documentation-only or unchanged ranges report explicit success; failed scope detection and absent/invalid outputs fail closed. Pull-request scope is cumulative from the merge base, so a final documentation commit cannot hide an earlier native/API change. A missing comparison commit remains an error; manual dispatch is the explicit full-run alternative.

The existing entrypoint's default full-shell path is retained. The new opt-in core mode checks host GLib availability, verifies the vendored source inventory and exact repair, checks formatting, runs locked all-target Clippy without shell features, and executes the complete locked no-default-feature test suite without a test-name filter. The OpenAPI parity and negative method/path tests in `desktop/src/protocol.rs` remain part of that suite; no copied allowlist or alternate production implementation is introduced.

## Prerequisites and limits

The configured runner is Ubuntu 24.04 amd64 with Bash, Python 3 and rustup. It installs `build-essential`, `pkg-config` and `libglib2.0-dev`; GLib/GObject/GIO headers and runtime libraries are needed for the optimized patched-GLib regression. Rust comes from `rust-toolchain.toml` (1.98.1 at this change), with Clippy and rustfmt. Rust dependency resolution is pinned by `desktop/Cargo.lock`, exact manifest constraints and `--locked`; vendored files are checked before Cargo runs. Installed Ubuntu library/package versions are printed in the job log and track distribution updates rather than the separate Ubuntu 26.04 overlay lock.

The core job does not require Node, GTK/WebKit, a display session, an API/database process or a real credential vault. Native integration fixtures create their own bounded loopback listeners and temporary files and use test vaults. The [default full desktop path](../../desktop/README.md#development-checks) still requires the Ubuntu 26.04 amd64 pinned header overlay and compatible host runtime libraries. The full Tauri dependency requirements are documented by [Tauri](https://v2.tauri.app/start/prerequisites/); the configured hosted OS is listed in [GitHub's runner image documentation](https://github.com/actions/runner-images/blob/main/images/ubuntu/Ubuntu2404-Readme.md).

This qualification covers native broker/request-policy and API-contract regression checks. It does not establish rendered native GUI behavior, real Secret Service read/write/delete, chooser/save dialogs, packaged deep links, installation, distribution compatibility, signing or updates. Those acceptance gates remain in [the desktop runtime evidence](2026-10-18-desktop.md) and F36.

## Hosted qualification

The implementation merged through [PR #121](https://github.com/MimoAlexer/OpenTrack/pull/121). On the subsequent [PR #122 source `aaf6bfe6981041dfcda0c428b532b463c1637754`](https://github.com/MimoAlexer/OpenTrack/tree/aaf6bfe6981041dfcda0c428b532b463c1637754), [the hosted `native-contracts` job](https://github.com/MimoAlexer/OpenTrack/actions/runs/39472175815/job/118798847383) executed `desktop/scripts/check.sh --core` and passed on 20 October 2026. This was a full core execution, not the documentation-only reporting path.

The job passed formatting, strict all-target Clippy and vendor verification, followed by **47 tests**: 21 unit tests, five attachment tests, one optimized GLib regression and 20 native-boundary tests. There were zero failures, ignored tests or filtered tests. The executed unit tests include published OpenAPI route parity, unsupported methods, malformed/scoped identifiers, credential-header rejection and bounded project requests.

The same run's [scope job](https://github.com/MimoAlexer/OpenTrack/actions/runs/39472175815/job/118798760916) passed all **14 scope tests** and **six desktop entrypoint tests**, preserving documentation-only reporting, failed-scope rejection, cumulative native/API input detection and dependency/vendor/Cargo failure propagation.

A read-only check of `main` protection on 20 October 2026 confirmed strict required-status enforcement with `native-contracts` alongside `verify` and both AMD64/ARM64 Docker runtime checks. This completes the narrow hosted broker/API-contract qualification requested by #120. Rendered native GUI behavior, real credential-vault integration, chooser/save dialogs, packaging, installation, deep-link association, signing, updates and platform acceptance remain separate gates; none is established by this core CI result.
